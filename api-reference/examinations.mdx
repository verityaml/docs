title: Examinations
description: Create, manage, and track compliance examinations — including request items, evidence, uploads, and response package generation

## List examinations

<ParamField path="method" type="GET">`/api/examinations`</ParamField>

Returns all examinations for the current organization.

<ResponseField name="data.examinations" type="array">
  Array of examination objects with `id`, `name`, `type`, `status`, `examiner`, `dateReceived`, `responseDeadline`, `createdAt`, `updatedAt`.
</ResponseField>

---

## Create examination

<ParamField path="method" type="POST">`/api/examinations`</ParamField>

<ParamField body="type" type="string" required>
  Examination type. One of: `regulatory`, `bank_partner`, `internal_audit`.
</ParamField>

<ParamField body="examiner" type="string">
  Name of the examining entity (e.g., "FDIC", "OCC").
</ParamField>

<ParamField body="name" type="string">
  Display name for the examination.
</ParamField>

<ParamField body="dateReceived" type="string">
  ISO date string when the request letter was received.
</ParamField>

<ParamField body="responseDeadline" type="string" required>
  ISO date string for the response deadline.
</ParamField>

<ResponseField name="data.examination" type="object">
  The created examination with auto-generated ID (e.g., `EX-2026-001`). Status starts as `preparing`.
</ResponseField>

## Delete examination

<ParamField path="method" type="DELETE">`/api/examinations/{examId}`</ParamField>

Deletes the examination and all associated data (request items, evidence, uploads). Cleans up files from storage.

---

## Archive examination

<ParamField path="method" type="POST">`/api/examinations/{examId}/archive`</ParamField>

Transitions the examination to `archived` status. Only valid from `submitted` or `findings_received`.

---

## Unarchive examination

<ParamField path="method" type="POST">`/api/examinations/{examId}/unarchive`</ParamField>

Transitions an archived examination back to `in_progress`. Idempotent — if already `in_progress`, returns 200 with current record.

---

## Update request item

<ParamField path="method" type="PATCH">`/api/examinations/{examId}/items/{itemId}`</ParamField>

</ParamField>

</ParamField>

## Upload evidence

<ParamField path="method" type="POST">`/api/examinations/{examId}/items/{itemId}/evidence`</ParamField>

Accepts either file upload (`multipart/form-data`) or external URL (`application/json`).

**File upload:**

<ParamField body="file" type="file" required>
  The evidence file. Max 50 MB. Allowed: PDF, DOCX, XLSX, CSV, PNG, JPG.
</ParamField>

**URL mode:**

<ParamField body="url" type="string" required>
  External URL to the evidence document.
</ParamField>

<ParamField body="fileName" type="string">
  Display name for the URL evidence.
</ParamField>

---

## Delete evidence

<ParamField path="method" type="DELETE">`/api/examinations/{examId}/items/{itemId}/evidence/{evidenceId}`</ParamField>

Deletes the evidence attachment and cleans up the file from storage.

---

## Upload examination file

<ParamField path="method" type="POST">`/api/examinations/{examId}/upload`</ParamField>

Uploads an examination request letter for AI parsing. Triggers the `parse-examination` background job.

<ParamField body="file" type="file" required>
  The request letter file. Max 50 MB. Allowed: PDF, CSV, PNG, JPG.
</ParamField>

<ResponseField name="data.uploadId" type="string">
  Upload ID for tracking parse progress.
</ResponseField>

<ResponseField name="data.status" type="string">
  Initial status: `pending`.
</ResponseField>

---
