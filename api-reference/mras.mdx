---
title: MRAs
description: Matters Requiring Attention — create, track, and remediate examination findings
---

MRAs (Matters Requiring Attention) track examination findings and their remediation. They are created from archived examinations and linked to specific request items.

## List MRAs

<ParamField path="method" type="GET">`/api/mras`</ParamField>

Returns all MRAs for the organization, enriched with examination names.

<ParamField query="status" type="string">
  Filter by status (comma-separated). Valid values: `open`, `remediation_in_progress`, `closed`.
</ParamField>

<ResponseField name="data.mras" type="array">
  Array of MRA objects. Each includes:
  - `id` — Human-readable ID (e.g., `MRA-2026-001`)
  - `title` — Finding title
  - `description` — Finding description
  - `pillar` — Regulatory domain
  - `status` — `open`, `remediation_in_progress`, or `closed`
  - `issuedDate` — When the finding was issued
  - `examinationId` — Parent examination
  - `examinationName` — Parent examination name
</ResponseField>

---

## Create MRA

<ParamField path="method" type="POST">`/api/examinations/{examId}/mras`</ParamField>

Creates a new MRA for an archived examination.

<ParamField path="examId" type="string" required>
  Examination ID. Must be in `archived` status.
</ParamField>

<ParamField body="title" type="string" required>
  Finding title.
</ParamField>

<ParamField body="description" type="string">
  Detailed finding description.
</ParamField>

<ParamField body="pillar" type="string" required>
  Regulatory pillar (e.g., `internal_controls`, `cdd_kyc`).
</ParamField>

<ParamField body="issuedDate" type="string">
  ISO date when the finding was issued.
</ParamField>

<ParamField body="linkedRequestItemIds" type="array" required>
  Array of request item IDs from the examination that led to this finding. At least one required.
</ParamField>

<ResponseField name="data.mra" type="object">
  The created MRA with auto-generated ID (e.g., `MRA-2026-001`).
</ResponseField>

---

## Update MRA

<ParamField path="method" type="PATCH">`/api/mras/{mraId}`</ParamField>

<ParamField path="mraId" type="string" required>
  MRA ID (e.g., `MRA-2026-001`).
</ParamField>

<ParamField body="title" type="string">
  Updated title.
</ParamField>

<ParamField body="description" type="string">
  Updated description.
</ParamField>

<ParamField body="issuedDate" type="string">
  Updated issued date.
</ParamField>

<ParamField body="status" type="string">
  New status. Transitions are forward-only: `open` → `remediation_in_progress` → `closed`.
</ParamField>

<Warning>
Status transitions are forward-only. You cannot move an MRA back to a previous status.
</Warning>

<ResponseField name="data.evidence" type="array">

## Upload remediation evidence

<ParamField path="method" type="POST">`/api/mras/{mraId}/evidence`</ParamField>

Upload a file demonstrating remediation progress.

<ParamField body="file" type="file" required>
  The evidence file. Max 50 MB. Allowed: PDF, DOCX, XLSX, CSV, PNG, JPG.
</ParamField>

<ResponseField name="data.evidence" type="object">
  The created evidence record.
</ResponseField>
