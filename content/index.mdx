## Detection tools tell you what happened. Verity proves your program works.

Verity helps compliance teams continuously prove their programs work. Monitor readiness across regulatory domains with scored criteria and evidence tracking. Upload examination request letters to get them parsed into trackable items mapped to the FFIEC framework. Assign evidence collection to your team, search a regulatory reference library for guidance, and archive everything for future examinations.

## What Verity does

<CardGroup cols={2}>
  <Card title="Compliance command center" icon="gauge-high">
    Dashboard with readiness scores computed from evidence status across all regulatory domains. Switch between programs, see per-domain scores and gap counts, and drill into criteria detail tables.
  </Card>
  <Card title="Bank-readiness scoring" icon="chart-line">
    Novelty-weighted additive scoring rewards evidence diversity — first evidence is 100 points, near-duplicates contribute close to zero. Per-domain configurable thresholds. BSA/AML covers 5 FFIEC pillars; Third-Party Oversight covers 8 OCC 2023-17 monitoring areas.
  </Card>
  <Card title="Regulatory reference library" icon="book">
    Browse and search across FFIEC guidance, FinCEN advisories, OCC interagency guidance, and deficiency patterns. Semantic search powered by Voyage AI embeddings.
  </Card>
  <Card title="Examination parser" icon="file-import">
    Upload a PDF request letter. The system parses each line item and maps it to FFIEC sections, regulatory pillars, and evidence types. Items stream in one-by-one as they're extracted.
  </Card>
  <Card title="Examination workflow tracker" icon="list-check">
    Track evidence collection across your team. See progress by pillar, by assignee, by status, or by timeline. Upload evidence files against each request item.
  </Card>
  <Card title="Cross-obligation evidence linking" icon="link">
    When evidence is uploaded to one obligation, the system automatically finds semantically similar request items on other active obligations and creates evidence links for human review.
  </Card>
  <Card title="Evidence bridge" icon="diagram-project">
    Criterion-linked evidence propagates deterministically to request items sharing the same scoring key — one source of truth, reused across every obligation mapped to the same regulatory requirement.
  </Card>
  <Card title="Library auto-classification" icon="wand-magic-sparkles">
    Files uploaded to the evidence library are text-extracted, chunked by heading, embedded, and matched against scoring criteria via pgvector similarity — high-confidence matches auto-link with score updates.
  </Card>
  <Card title="Response archive" icon="box-archive">
    Archive complete examination packages. Search across all past examinations. Track remediation items and their resolution.
  </Card>
  <Card title="Evidence library" icon="folder-open">
    Centralised org-wide evidence view with auto-classification via embedding similarity, source type filtering, download, criteria linking, and Google Drive connector integration.
  </Card>
  <Card title="Score trends" icon="chart-area">
    Trends page with Recharts line charts, date range presets, auto-bucketing, and domain filter. Historical v1 scores rendered as dashed series alongside v2 additive scores.
  </Card>
  <Card title="Score notifications" icon="bell">
    Notification bell with unread count, slide-out panel with date grouping. Score changes, per-domain threshold crossings, program milestones, and drift corrections.
  </Card>
  <Card title="Report generation" icon="file-export">
    Export examination response packages as PDF binders or ZIP archives. Export compliance readiness reports as PDF or CSV.
  </Card>
</CardGroup>

## Tech stack

| Layer | Technology |
|-------|-----------|
| Frontend + API | Next.js 16 (App Router) |
| Database | RDS PostgreSQL + pgvector |
| ORM | Drizzle |
| Auth | BetterAuth |
| UI | shadcn/ui + Tailwind CSS v4 |
| LLM | Anthropic Claude (via Vercel AI SDK) |
| PDF Extraction | unpdf (reference-based extraction) |
| Embeddings | Voyage AI (`voyage-law-2`) |
| Background Jobs | SQS + Lambda |
| File Storage | S3 |
| Email | SES |
| Desktop | Tauri v2 (macOS) |
| Hosting | AWS (ECS Fargate, CloudFront) |
