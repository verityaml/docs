When an examination is complete, archive it. The archive preserves the full examination package — every request item, every uploaded evidence file, all notes and status history.

## Search across examinations

The archive search lets you query across all past examinations. Looking for how you handled a specific regulatory topic last cycle? Search for it. The results show which examination contained it, what evidence was provided, and what the outcome was.

<Tip>
This is the "institutional memory" that most compliance teams lack. The second examination cycle takes less time because you can reference what worked before.
</Tip>

## Remediation item tracking

If the examination results in findings requiring follow-up, track them as **remediation items** directly from the archived examination.

### Creating a remediation item

From an archived examination, click **Create Remediation Item**. Each item requires:
- A title describing the finding
- At least one linked request item from the examination
- The regulatory category it relates to

Remediation items are assigned human-readable IDs like `REM-2026-001`.

### Remediation lifecycle

```
open → remediation_in_progress → closed
```

Status transitions are forward-only — an item moves from identified through active remediation to closed. Each remediation item records:

| Field | Description |
|-------|-------------|
| Finding text | The examiner's finding |
| Category | Regulatory category (uses the regulation type's categories) |
| Status | Current lifecycle stage |
| Issued date | When the finding was issued |
| Remediation evidence | Files uploaded to demonstrate remediation |
| Linked request items | Original examination items that led to the finding |

### Remediation evidence

Upload evidence files directly against each remediation item to demonstrate progress. The same file types and size limits apply as examination evidence (PDF, DOCX, XLSX, CSV, PNG, JPG — max 50 MB).

<Note>
When you create a new examination, an **open remediation items banner** on the create page shows how many items from previous examinations are still unresolved.
</Note>

## Reopening archived examinations

Sometimes an archived examination needs to be revisited — a follow-up request arrives, evidence needs updating, or the archive was premature. The **Reopen Examination** button transitions the examination back to "In Progress" and returns you to the standard examination workflow.

A confirmation dialog asks you to confirm before the transition happens. Once reopened, all request items become editable again and the examination reappears in the active examinations list.

## Correspondence

Archived examinations support post-exam correspondence uploads — findings reports, follow-up letters, and other documents that arrive after the initial examination cycle. These are stored alongside the archived package for a complete record.
