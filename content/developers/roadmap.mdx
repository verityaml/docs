## Planned — post-partnership

### Evidence table rename

Rename `evidence_attachments` to `evidence` in a cleanup migration. Pure naming change — no schema logic affected.

### Consent order lifecycle

- Container-level lifecycle: `issued` &rarr; `remediation_in_progress` &rarr; node-level closure &rarr; `order_lifted`
- Different from examination lifecycle — container never fully archives
- Cross-department assignment for findings spanning multiple business lines
- Recurring deadline support via Inngest scheduled functions (call reports quarterly, attestations monthly)

### Schema rename: examinations to obligations

Rename the `examinations` table to `obligations` to reflect the generic compliance obligation container. Cascades to uploads, correspondence, FK columns, and storage paths.

### Bulk assignment

Select multiple request items, assign to one person. API (`PATCH /items/bulk`) + floating action bar with checkbox selection.

### Member permission boundary

API-level check: members can only update items assigned to them, admins can update any. UI read-only mode for non-assigned items.

### Progress report generation

Structured quarterly progress reports for regulators. Planned for consent order support.

## Infrastructure

### Performance

- Database indexes on `session(user_id)`, `invitation(organization_id, email)`, `audit_log(org_id, created_at)`
- Partial unique indexes to prevent duplicate linked accounts and pending invites
- Remove Voyage AI rate-limit sleep after upgrading from free tier
- GIN index on `scoring_criteria.linked_evidence` for evidence library queries at scale
- Index on `evidence_attachments(org_id)` for evidence library filtering

### Auth and tenancy

- Optional org at signup (allow users to sign up without creating an org)
- Org slug collision handling (append numeric suffix or show clear error)
- Cross-tenant isolation tests
- Atomic signup (single server-side endpoint that rolls back on failure)

### RLS

- `SET LOCAL app.current_user_id` in Drizzle transaction wrapper for per-user RLS enforcement

### Accessibility

- `Input` component: `React.forwardRef` for form library compatibility
- `ProgressBar`: optional `ariaLabel` / `ariaValueText` props
