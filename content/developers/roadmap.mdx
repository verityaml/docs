## AWS migration

Migration from Vercel + Supabase + Inngest to AWS-native services (ECS Fargate, RDS, S3, SQS+Lambda, Bedrock, SES). 8-phase plan over ~5 weeks, funded by $5k-25k in AWS credits. Adds CloudFront CDN, AWS WAF, and CDK Pipelines for IaC.

**Phases 1–4 and CI/CD consolidation (Phase 4.75)** are complete. Background jobs run on SQS + Lambda, file storage uses S3, the database runs on RDS, and GitHub Actions handles CI/CD with a staging-first pipeline gated by E2E tests. **Phase 5 (Provider Swap + Cutover)** — Supabase/Inngest/Vercel removal, DNS cutover — is not yet started. SES email is already live.

See the full [AWS migration plan](/developers/aws-migration) for architecture diagrams, cost analysis, and phase details.

Renamed the `examinations` table to `obligations` in PR #304. Cascaded to uploads, correspondence, FK columns, and storage paths.

### Bulk assignment

### ~~Member permission boundary~~ — Complete

`requireWriteAccess()` API helper enforces that members can only PATCH request items assigned to them. Admins/owners bypass. UI auto-computes read-only state with lock banner and disabled controls. Done in PR #317.

### Progress report generation

Structured quarterly progress reports for regulators. Planned for consent order support.
