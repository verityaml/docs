## In progress

### Google Drive Connector

External integration for automated evidence discovery and classification. Feature-flagged behind `connectors_enabled` in organization metadata.

**Done:**
- Connector schema with KMS envelope encryption for OAuth credentials
- Google Drive OAuth flow (authorize + callback with PKCE)
- Sync pipeline: SQS → Lambda → list files → batch LLM classification (Haiku) → score deltas
- Connector UI: folder picker, file list with classification badges, sync results
- Stale file detection and `consecutiveMissing` tracking
- Google Drive logo on connector cards and integrations panel
- Program label shown as inline tag on folder pills
- Linked criteria hover popover on evidence table
- Proactive OAuth token refresh for Google Drive API routes
- `clearExistingItems()` memory-safe DELETE (no `.returning()`) for Lambda

**Remaining:**
- Multi-provider support framework (SharePoint, OneDrive planned)

### Agentic File Classification (Specified)

Upgrade connector classification from single-shot to agentic Haiku with tools — folder exploration, file content preview (transient, never stored), on-demand criteria lookup. Structured triage with a 10-peek budget and fallback to single-shot on tool exhaustion. Feature-flagged per org.

**Status:** Spec complete (requirements, design, tasks, diagrams). Not yet in implementation.

### AWS Provider Swap + Cutover (Not Started)

AWS migration Phase 5 — SES email (replacing Resend), remove Supabase storage provider, remove rate-limit sleeps, E2E on staging, SNS alarm notifications, DNS cutover, Inngest/Anthropic/Supabase/Resend removal, Vercel decommission.

### Desktop App

**Done (phases 1–7, 10–11):**
- Onboarding flow, dashboard snapshot, system tray
- Cookie-based SSR auth, cross-origin token bootstrap
- Dev-mode polling auth fallback
- 12 post-deploy smoke tests

**Remaining:**
- Phase 0: Apple Developer enrollment

## Planned — post-partnership

### Notifications

- Notification preferences UI — settings page to enable/disable notification types per user (P2)
- Email digest notifications — daily/weekly summary of score changes delivered via SES (P3)
- ~~`applyScoreDelta` return eventId~~ — Done in PR #360. `applyScoreDelta()` now returns `eventId` for notification→score event deep-linking (#292)

### Consent order lifecycle

- Container-level lifecycle: `issued` → `remediation_in_progress` → node-level closure → `order_lifted`
- Different from obligation lifecycle — container never fully archives
- Cross-department assignment for findings spanning multiple business lines
- Recurring deadline support via scheduled background jobs (call reports quarterly, attestations monthly)

### Bulk assignment

Select multiple request items, assign to one person. API (`PATCH /items/bulk`) + floating action bar with checkbox selection.

### ~~Member permission boundary~~ — Complete

`requireWriteAccess()` API helper enforces that members can only PATCH request items assigned to them. Admins/owners bypass. UI auto-computes read-only state with lock banner and disabled controls. Done in PR #317.

### Progress report generation

Structured quarterly progress reports for regulators. Planned for consent order support.
