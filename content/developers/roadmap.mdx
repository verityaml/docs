## Recently completed

### Evidence Bridge (Complete)

Criteria → request item evidence propagation. When evidence is linked to a scoring criterion, auto-suggest on request items sharing the same `definition_key`. Extends `evidence_links` table with `source_criterion_id` and `match_type`. Async via existing propagate-evidence SQS queue.

### Google Drive Connector (Complete)

External integration for automated evidence discovery and classification. Feature-flagged behind `google_drive` in organization metadata. OAuth-connected Google Drive sync, metadata-only file classification via LLM (Claude Haiku), auto-links evidence to scoring criteria. Watched folders, sync progress, stale file indicators, disconnect cleanup.

### Agentic File Classification (Complete)

Upgraded connector classification from single-shot to agentic Haiku with tools — folder exploration, file content preview (transient, never stored), on-demand criteria lookup. Structured triage with a 10-peek budget and fallback to single-shot on tool exhaustion. Feature-flagged per org (`agentic_classification`). OAuth scope upgrades to `drive.readonly` when enabled. Golden set expanded to 41 test cases.

### AWS Provider Swap + Cutover (Complete)

AWS migration Phase 5 — SES email (replacing Resend), Supabase storage provider removed, rate-limit sleeps removed, E2E on staging, SNS alarm notifications, DNS cutover. Inngest/Anthropic/Supabase/Resend removed, Vercel decommissioned. Cutover live 2026-03-17.

### Event-Based Score Recomputation (Complete)

Delta-based scoring pipeline replacing scattered `recomputeDomainScore()` calls. `applyScoreDelta()` as single entry point, `score_change_events` audit table, program score caching, auto-snapshots, nightly full recompute via EventBridge Lambda. All migrations applied staging and production.

## Planned — post-partnership

### Notifications

- Notification preferences UI — settings page to enable/disable notification types per user (P2)
- Email digest notifications — daily/weekly summary of score changes delivered via SES (P3)
- ~~`applyScoreDelta` return eventId~~ — Done in PR #360. `applyScoreDelta()` now returns `eventId` for notification→score event deep-linking (#292)

### Consent order lifecycle

- Container-level lifecycle: `issued` → `remediation_in_progress` → node-level closure → `order_lifted`
- Different from obligation lifecycle — container never fully archives
- Cross-department assignment for findings spanning multiple business lines
- Recurring deadline support via scheduled background jobs (call reports quarterly, attestations monthly)

### Bulk assignment

Select multiple request items, assign to one person. API (`PATCH /items/bulk`) + floating action bar with checkbox selection.

### ~~Member permission boundary~~ — Complete

`requireWriteAccess()` API helper enforces that members can only PATCH request items assigned to them. Admins/owners bypass. UI auto-computes read-only state with lock banner and disabled controls. Done in PR #317.

### Progress report generation

Structured quarterly progress reports for regulators. Planned for consent order support.
