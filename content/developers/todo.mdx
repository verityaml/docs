## Active — Runway Partnership

Partnership start: March 3, 2026. 60-day review: ~May 2. End: ~June 1.

### Domain-level evidence upload — Complete

Multi-file upload directly on domain detail pages. Supports drag-and-drop and maps files to the parent domain's scoring criteria.

### Score history snapshots — Complete

Point-in-time score capture with comparison mode. View how readiness scores change over time across domains.

### Evidence library — In progress

Centralised org-wide evidence view with context-free upload, filters, download, and delete. Schema, API, and UI are complete. Remaining:

- Unit tests for API routes (GET list, POST upload, DELETE, GET download)
- E2E tests (upload, filter, delete, download)
- Extract shared upload component from `EvidenceUploadSection` and `DomainUploadZone`

### Readiness report export — Complete

Export compliance readiness reports as PDF binders or pillar-organised ZIP archives from the dashboard.

### Create program wizard + editing — Complete

Self-service program creation for any regulation type in `REGULATION_CONFIG`. Includes a 4-step wizard (regulation type selection, domain configuration, criteria preview with template population, baseline assessment), programs management page, and program settings page with rename, domain toggle, and delete.
