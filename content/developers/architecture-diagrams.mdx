## Current production stack

Verity runs on **Vercel** (compute), **Supabase** (Postgres + Storage), and **Inngest** (4 background jobs), with Voyage AI for embeddings, Claude for document parsing, and Resend for email. Estimated cost: **~$50-60/mo**.

```
Browser → Cloudflare DNS → Vercel (US region)
                            ├── Next.js 16 App Router (SSR + API routes)
                            ├── proxy.ts (session gate)
                            ├── BetterAuth (self-hosted auth)
                            └── Inngest (4 background functions)
                                 ├── parse-examination (~7min, rate-limited)
                                 ├── auto-match-evidence
                                 ├── propagate-evidence
                                 └── backfill-evidence-links
                            │
                  ┌─────────┼──────────┐
                  ▼         ▼          ▼
           Supabase     Voyage AI   Claude Sonnet 4.6
           PostgreSQL   voyage-law-2  (Vercel AI SDK)
           + pgvector
           + Storage
```

### Service breakdown

| Service | Role | Cost |
|---------|------|------|
| Vercel | Next.js hosting, SSR, API routes, preview deploys | ~$20/mo |
| Supabase PostgreSQL | Database with pgvector, RLS, transaction-mode pooler | ~$25/mo |
| Supabase Storage | Evidence files, exam uploads, reports (50MB max) | Included |
| Inngest | 4 background functions with step-based execution | Free tier |
| Voyage AI | voyage-law-2 embeddings (1024-dim), legal domain | Free tier |
| Anthropic Claude | Document parsing via Vercel AI SDK (~50 parses/mo) | ~$5-15/mo |
| Resend | Transactional email (password resets, invitations) | Free tier |
| GitHub Actions | PR checks only (lint, test, build) — no deploy | Free tier |

### Request flow

```
Page load:    Browser → Vercel → proxy.ts (cookie check) → Server Component → Drizzle → Supabase PG
Static asset: Browser → Vercel edge (cached)
API call:     Browser → Vercel → API route → BetterAuth session → Drizzle → Supabase PG
Background:   API route → inngest.send() → Inngest step functions → Voyage AI / Claude / Supabase PG
```

function ServiceBox({ x, y, width = 140, height = 80, color, label, sublabel, onClick }) {
  return (
    <g style={{ cursor: onClick ? "pointer" : "default" }} onClick={onClick}>
      <rect x={x} y={y} width={width} height={height} rx={8} fill={COLORS.white} stroke={color} strokeWidth={2} />

        </text>
      )}
    </g>
  );
}

function ZoneBox({ x, y, width, height, label, color, borderColor, children }) {
  return (
    <g>

        {label}
      </text>
      {children}
    </g>
  );
}

function Arrow({ x1, y1, x2, y2, label, dashed, color = "#999" }) {
  const midX = (x1 + x2) / 2;
  const midY = (y1 + y2) / 2;
  const id = `arrow-${x1}-${y1}-${x2}-${y2}`;
  return (
    <g>
      <defs>
        <marker id={id} markerWidth={8} markerHeight={6} refX={8} refY={3} orient="auto">
          <polygon points="0 0, 8 3, 0 6" fill={color} />
        </marker>
      </defs>
      <line x1={x1} y1={y1} x2={x2} y2={y2} stroke={color} strokeWidth={1.5} strokeDasharray={dashed ? "6 3" : undefined} markerEnd={`url(#${id})`} />
      {label && (
        <text x={midX} y={midY - 6} textAnchor="middle" fontSize={9} fill="#888" fontFamily="JetBrains Mono, monospace">
          {label}
        </text>
      )}
    </g>
  );
}

function ElbowArrow({ x1, y1, x2, y2, midY: customMidY, label, color = "#999" }) {
  const midY = customMidY || (y1 + y2) / 2;
  const path = `M ${x1} ${y1} L ${x1} ${midY} L ${x2} ${midY} L ${x2} ${y2}`;
  const id = `elbow-${x1}-${y1}-${x2}-${y2}`;
  return (
    <g>
      <defs>
        <marker id={id} markerWidth={8} markerHeight={6} refX={8} refY={3} orient="auto">
          <polygon points="0 0, 8 3, 0 6" fill={color} />
        </marker>
      </defs>
      <path d={path} fill="none" stroke={color} strokeWidth={1.5} markerEnd={`url(#${id})`} />
      {label && (
        <text x={(x1 + x2) / 2} y={midY - 6} textAnchor="middle" fontSize={9} fill="#888" fontFamily="JetBrains Mono, monospace">
          {label}
        </text>
      )}
    </g>
  );
}

  );
}
