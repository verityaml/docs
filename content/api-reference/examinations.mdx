---
title: Obligations
description: Create, manage, and track regulatory obligations — including request items, evidence, uploads, and response package generation
---

<Note>
Obligations were previously called "examinations" in the codebase. The table was renamed but API routes now live at `/api/obligations/`. IDs use the format `OB-2026-001`.
</Note>

## List obligations

<ParamField path="method" type="GET">`/api/obligations`</ParamField>

Returns all obligations for the current organization.

<ResponseField name="data.obligations" type="array">
  Array of obligation objects with `id`, `name`, `type`, `status`, `examiner`, `dateReceived`, `responseDeadline`, `obligationType`, `regulationType`, `createdAt`, `updatedAt`.
</ResponseField>

---

## Create obligation

<ParamField path="method" type="POST">`/api/obligations`</ParamField>

<ParamField body="type" type="string" required>
  Obligation type. One of: `regulatory`, `bank_partner`, `internal_audit`.
</ParamField>

<ParamField body="examiner" type="string">
  Name of the examining entity (e.g., "FDIC", "OCC").
</ParamField>

<ParamField body="name" type="string">
  Display name for the obligation.
</ParamField>

<ParamField body="dateReceived" type="string" required>
  ISO date string when the request letter was received.
</ParamField>

<ParamField body="responseDeadline" type="string" required>
  ISO date string for the response deadline.
</ParamField>

<ParamField body="obligationType" type="string">
  One of: `examination`, `consent_order`, `call_report`, `attestation`. Defaults to `examination`.
</ParamField>

<ParamField body="regulationType" type="string">
  One of: `bsa_aml`, `third_party_oversight`. Defaults to `bsa_aml`.
</ParamField>

<ResponseField name="data.obligation" type="object">
  The created obligation with auto-generated ID (e.g., `OB-2026-001`). Status starts as `preparing`.
</ResponseField>

## Update obligation

<ParamField path="method" type="PATCH">`/api/obligations/[id]`</ParamField>

<ParamField body="status" type="string">
  One of: `preparing`, `in_progress`, `submitted`, `findings_received`, `archived`.
</ParamField>

<ParamField body="type" type="string">
  Obligation type.
</ParamField>

<ParamField body="examiner" type="string">
  Examiner name.
</ParamField>

<ParamField body="name" type="string">
  Display name.
</ParamField>

<ParamField body="dateReceived" type="string">
  ISO date string.
</ParamField>

<ParamField body="responseDeadline" type="string">
  ISO date string.
</ParamField>

<Note>
Archived obligations can only update `findingsReportPath`.
</Note>

---

## Delete obligation

<ParamField path="method" type="DELETE">`/api/obligations/[id]`</ParamField>

Deletes the obligation and all associated data (request items, evidence, uploads). Cleans up files from S3.

---

## Archive obligation

<ParamField path="method" type="POST">`/api/obligations/[id]/archive`</ParamField>

Transitions the obligation to `archived` status. Only valid from `submitted` or `findings_received`.

---

## Unarchive obligation

<ParamField path="method" type="POST">`/api/obligations/[id]/unarchive`</ParamField>

Transitions an archived obligation back to `in_progress`. Idempotent — if already `in_progress`, returns 200 with current record.

---

## Upload request letter

<ParamField path="method" type="POST">`/api/obligations/[id]/upload`</ParamField>

Uploads a request letter for AI parsing. Triggers the `parse-examination` background job which extracts request items using unpdf and Claude.

<ParamField body="file" type="file" required>
  The request letter file. Max 50 MB. Allowed: PDF, CSV, PNG, JPG.
</ParamField>

<ResponseField name="data.uploadId" type="string">
  Upload ID for tracking parse progress.
</ResponseField>

<ResponseField name="data.status" type="string">
  Initial status: `pending`.
</ResponseField>

---

## List request items

<ParamField path="method" type="GET">`/api/obligations/[id]/items`</ParamField>

<ParamField query="after" type="number">
  Sort order cursor for polling during parse (returns items with `sortOrder` greater than `after`).
</ParamField>

<ResponseField name="data.items" type="array">
  Array of request items with `id` (UUID), `itemNumber`, `originalText`, `ffiecSection`, `category`, `evidenceType`, `guidanceNotes`, `status`, `assigneeId`, `dueDate`, `sortOrder`.
</ResponseField>

<ResponseField name="data.parseStatus" type="string">
  Upload parse status: `pending`, `processing`, or `completed`.
</ResponseField>

<ResponseField name="data.totalCount" type="number">
  Total number of request items.
</ResponseField>

---

## Create request item

<ParamField path="method" type="POST">`/api/obligations/[id]/items`</ParamField>

Accepts a single item or an array for bulk insert.

<ParamField body="originalText" type="string" required>
  The examiner's request text.
</ParamField>

<ParamField body="category" type="string" required>
  Regulatory category (e.g., `internal_controls`, `cdd_kyc`). Valid categories are defined per regulation type in `REGULATION_CONFIG`.
</ParamField>

<ParamField body="ffiecSection" type="string">
  Specific FFIEC section reference.
</ParamField>

<ParamField body="evidenceType" type="string">
  Type of evidence that satisfies this request.
</ParamField>

---

## Update request item

<ParamField path="method" type="PATCH">`/api/obligations/[id]/items/[itemId]`</ParamField>

<ParamField body="originalText" type="string">
  Updated request text.
</ParamField>

<ParamField body="category" type="string">
  Updated category assignment.
</ParamField>

<ParamField body="assigneeId" type="string">
  User ID to assign the item to.
</ParamField>

<ParamField body="dueDate" type="string">
  ISO date string for the item deadline.
</ParamField>

<ParamField body="status" type="string">
  Item status: `not_started`, `in_progress`, `uploaded`, `needs_rework`, `reviewed`, or `ready`.
</ParamField>

<ParamField body="notes" type="string">
  Reviewer notes.
</ParamField>

<Note>
Updating any item on a `preparing` obligation automatically advances it to `in_progress`.
</Note>

## Upload evidence

<ParamField path="method" type="POST">`/api/obligations/[id]/items/[itemId]/evidence`</ParamField>

Accepts either file upload (`multipart/form-data`) or external URL (`application/json`).

**File upload:**

<ParamField body="file" type="file" required>
  The evidence file. Max 50 MB. Allowed: PDF, DOCX, XLSX, CSV, PNG, JPG.
</ParamField>

**URL mode:**

<ParamField body="url" type="string" required>
  External URL to the evidence document.
</ParamField>

<ParamField body="fileName" type="string">
  Display name for the URL evidence.
</ParamField>

<ParamField body="sourceSystem" type="string">
  Source system identifier (e.g., `sharepoint`, `google_drive`).
</ParamField>

---

## Delete evidence

<ParamField path="method" type="DELETE">`/api/obligations/[id]/items/[itemId]/evidence/[evidenceId]`</ParamField>

Deletes the evidence attachment and cleans up the file from S3.

---

## Evidence link count

<ParamField path="method" type="GET">`/api/obligations/[id]/evidence-link-count`</ParamField>

Returns the count of pending (auto-applied) evidence links for this obligation. Used for the sidebar badge.

<ResponseField name="data.count" type="number">
  Number of `auto_applied` (pending review) evidence links targeting items in this obligation.
</ResponseField>

## Report

<ParamField path="method" type="GET">`/api/obligations/[id]/report`</ParamField>

Returns aggregated report data including item counts by category and status.

<ParamField path="method" type="POST">`/api/obligations/[id]/report/generate`</ParamField>

Generates a response package and returns a signed download URL (valid 1 hour).

<ResponseField name="data.downloadUrl" type="string">
  Signed S3 URL for downloading the generated package.
</ResponseField>
