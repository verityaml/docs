## List programs

<ParamField path="method" type="GET">`/api/compliance-programs`</ParamField>

Returns all compliance programs for the organization, each with its domains.

<ResponseField name="data.programs" type="array">
  Array of program objects. Each program includes:
  - `id` — Human-readable ID (e.g., `CP-2026-001`)
  - `regulationType` — `bsa_aml` or `third_party_oversight`
  - `name` — Program display name
  - `currentScore` — Aggregated program score
  - `domains` — Array of domain objects with `id`, `domainKey`, `domainLabel`, `currentScore`, `totalCriteria`, `sufficientCriteria`, `partialCriteria`, `missingCriteria`
</ResponseField>

## Create program

<ParamField path="method" type="POST">`/api/compliance-programs`</ParamField>

Creates a new compliance program with domains and optional criteria from `SCORING_CRITERIA_DEFINITIONS`.

<ParamField body="name" type="string">
  Program display name.
</ParamField>

<ParamField body="regulationType" type="string" required>
  Regulation type from `REGULATION_CONFIG` (e.g., `bsa_aml`, `third_party_oversight`).
</ParamField>

<ParamField body="domains" type="array">
  Array of domain keys to include. Defaults to all categories for the regulation type.
</ParamField>

<ParamField body="populateCriteria" type="boolean">
  Whether to populate criteria from `SCORING_CRITERIA_DEFINITIONS`. Defaults to `true`.
</ParamField>

<ParamField body="baseline" type="object">
  Optional map of domain keys to initial evidence statuses for baseline assessment.
</ParamField>

<ResponseField name="data.program" type="object">
  The created program with domains and criteria.
</ResponseField>

## Get domain details

<ParamField path="method" type="GET">`/api/compliance-programs/[id]/domains/[domainId]`</ParamField>

<ParamField path="id" type="string" required>
  Program ID.
</ParamField>

<ParamField path="domainId" type="string" required>
  Domain ID (e.g., `CD-2026-001`).
</ParamField>

<ResponseField name="data.program" type="object">
  Parent program.
</ResponseField>

<ResponseField name="data.domain" type="object">
  Domain with `id`, `domainKey`, `domainLabel`, `currentScore`, criteria counts.
</ResponseField>

<ResponseField name="data.criteria" type="array">
  Array of scoring criteria for this domain. Each criterion includes:
  - `id` — Criterion ID (e.g., `SC-2026-001`)
  - `criterionText` — What the regulation requires
  - `regulatorySourceId` — FK to knowledge base
  - `criterionScore` — Unbounded novelty-weighted score
  - `evidenceStatus` — Auto-derived: `missing`, `partial`, or `sufficient`
  - `linkedEvidence` — JSONB array of linked evidence entries
  - `reviewerNotes` — Free-text notes
  - `sortOrder` — Display order
</ResponseField>

## Update scoring criterion

<ParamField path="method" type="PATCH">`/api/compliance-programs/[id]/domains/[domainId]/criteria/[criteriaId]`</ParamField>

Updates a scoring criterion's notes or linked evidence. Evidence status is auto-derived from the criterion's novelty-weighted score and cannot be set manually (returns 400 if `evidenceStatus` is included). Automatically recomputes scores via `recomputeAndCascade()`.

<ParamField body="reviewerNotes" type="string">
  Updated reviewer notes.
</ParamField>

<ParamField body="changeReason" type="string">
  Reason for the status change (recorded in score change events).
</ParamField>

<ParamField body="addEvidence" type="object">
  Link new evidence to this criterion.

  <ParamField body="addEvidence.sourceType" type="string" required>
    One of: `evidence_attachment`, `domain_upload`, `library`, `remediation`, `external_url`, `connector`.
  </ParamField>

  <ParamField body="addEvidence.sourceId" type="string" required>
    ID of the evidence source.
  </ParamField>

  <ParamField body="addEvidence.label" type="string" required>
    Display label for the evidence.
  </ParamField>
</ParamField>

<ParamField body="removeEvidence" type="object">
  Unlink evidence from this criterion.

  <ParamField body="removeEvidence.sourceType" type="string" required>
    Source type of the evidence to remove.
  </ParamField>

  <ParamField body="removeEvidence.sourceId" type="string" required>
    Source ID of the evidence to remove.
  </ParamField>
</ParamField>

<ParamField body="acceptSuggestion" type="object">
  Accept an auto-matched evidence suggestion.
</ParamField>

<ParamField body="dismissSuggestion" type="object">
  Dismiss an auto-matched evidence suggestion.
</ParamField>

<ResponseField name="data.criterion" type="object">
  Updated criterion with new `linkedEvidence` array.
</ResponseField>

<ResponseField name="data.domain" type="object">
  Updated domain with recomputed `currentScore`, criteria counts, and `programScore`.
</ResponseField>

<Note>
Maximum 50 evidence items per criterion. Score changes trigger `scoreChangeEvents` audit records. If the program score changes by 5+ points, an auto-snapshot is created (1 hour cooldown).
</Note>

## Score snapshots

<ParamField path="method" type="GET">`/api/compliance-programs/[id]/snapshots`</ParamField>

Returns cursor-paginated score snapshots for a program.

<ResponseField name="data.snapshots" type="array">
  Array of snapshot objects with `id` (e.g., `SNAP-2026-001`), `label`, `programScore`, `domainSnapshots` (JSONB), `trigger`, `createdBy`, and `createdAt`.
</ResponseField>

<ParamField path="method" type="POST">`/api/compliance-programs/[id]/snapshots`</ParamField>

Captures a point-in-time snapshot of the program's scores.

<ParamField body="label" type="string">
  Optional label (e.g., "Partnership Baseline", "Pre-60-Day Review").
</ParamField>

<ParamField body="reason" type="string">
  Optional reason for the snapshot.
</ParamField>

---

## Trigger auto-match

<ParamField path="method" type="POST">`/api/compliance-programs/[id]/auto-match`</ParamField>

Triggers AI-powered evidence matching between obligation evidence and the program's scoring criteria. Dispatches the `auto-match-evidence` SQS job.

<ParamField body="examinationIds" type="array">
  Array of obligation IDs to match evidence from.
</ParamField>

<ResponseField name="data.status" type="string">
  `matching` — the background job has been queued.
</ResponseField>

---

## Recompute scores

<ParamField path="method" type="POST">`/api/compliance-programs/[id]/recompute`</ParamField>

Recomputes all domain and program scores from current criteria states. Used for drift correction.
