---
title: Evidence links
description: Cross-obligation evidence linking — query, confirm, and reject auto-applied evidence links
---

Evidence links are automatically created when evidence uploaded to one obligation matches semantically similar request items on other active obligations. These endpoints let you query and manage those links.

## List evidence links for a request item

<ParamField path="method" type="GET">`/api/request-items/[itemId]/evidence-links`</ParamField>

Returns all evidence links targeting a specific request item.

<ParamField path="itemId" type="string" required>
  Request item UUID.
</ParamField>

<ParamField query="status" type="string">
  Filter by link status. Comma-separated values: `auto_applied`, `confirmed`, `rejected`.
</ParamField>

<ResponseField name="data.links" type="array">
  Array of evidence link objects. Each includes:
  - `id` — Link UUID
  - `sourceEvidenceId` — The evidence attachment being linked
  - `sourceRequestItemId` — The request item the evidence was uploaded to
  - `sourceObligationId` — The source obligation ID
  - `targetRequestItemId` — The request item being linked to
  - `targetObligationId` — The target obligation ID
  - `similarityScore` — Cosine similarity score (0–1)
  - `status` — `auto_applied`, `confirmed`, or `rejected`
  - `createdAt` — When the link was created
  - `reviewedAt` — When the link was confirmed or rejected (null if pending)
  - `evidence` — Nested evidence attachment details (fileName, fileSize, mimeType)
  - `sourceObligation` — Nested source obligation details (id, name)
  - `sourceItem` — Nested source request item details (itemNumber, originalText)
</ResponseField>

## Confirm or reject an evidence link

<ParamField path="method" type="PATCH">`/api/evidence-links/[linkId]`</ParamField>

Updates the status of an evidence link. Forward-only transitions from `auto_applied`.

<ParamField path="linkId" type="string" required>
  Evidence link UUID.
</ParamField>

<ParamField body="status" type="string" required>
  New status. One of: `confirmed`, `rejected`.
</ParamField>

<ResponseField name="data.link" type="object">
  The updated evidence link with `reviewedAt` timestamp and `reviewedBy` user ID set.
</ResponseField>

<Warning>
Status transitions are forward-only from `auto_applied`. You cannot change a `confirmed` link back to `auto_applied` or vice versa.
</Warning>

## Evidence link count for an obligation

<ParamField path="method" type="GET">`/api/obligations/[id]/evidence-link-count`</ParamField>

Returns the count of pending (auto-applied) evidence links for an obligation. Used for the sidebar badge.

<ParamField path="id" type="string" required>
  Obligation ID (e.g., `OB-2026-001`).
</ParamField>

<ResponseField name="data.count" type="number">
  Number of `auto_applied` (pending review) evidence links targeting items in this obligation.
</ResponseField>

---

## Get outbound links for an evidence attachment

<ParamField path="method" type="GET">`/api/evidence/[evidenceId]/links`</ParamField>

Returns all outbound evidence links originating from a specific evidence attachment. Used for the "Also linked to" indicators.

<ParamField path="evidenceId" type="string" required>
  Evidence attachment UUID.
</ParamField>

<ResponseField name="data.links" type="array">
  Array of outbound link objects. Each includes:
  - `id` — Link UUID
  - `targetRequestItemId` — The linked request item
  - `targetObligationId` — The target obligation
  - `similarityScore` — Match confidence
  - `status` — `auto_applied`, `confirmed`, or `rejected`
  - `targetObligation` — Nested obligation details (id, name)
  - `targetItem` — Nested request item details (itemNumber, originalText)
</ResponseField>
