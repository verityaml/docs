---
title: Remediation items
description: Remediation items — create, track, and remediate examination findings
---

Remediation items track examination findings and their remediation. They are created from archived examinations and linked to specific request items.

<Note>
Remediation items were previously called "MRAs" (Matters Requiring Attention). The API routes have been updated to `/api/remediation-items/`. IDs use the format `REM-2026-001`.
</Note>

## List remediation items

<ParamField path="method" type="GET">`/api/remediation-items`</ParamField>

Returns all remediation items for the organization, enriched with examination names.

<ParamField query="status" type="string">
  Filter by status (comma-separated). Valid values: `open`, `remediation_in_progress`, `closed`.
</ParamField>

<ResponseField name="data.remediationItems" type="array">
  Array of remediation item objects. Each includes:
  - `id` — Human-readable ID (e.g., `REM-2026-001`)
  - `title` — Finding title
  - `description` — Finding description
  - `category` — Regulatory category
  - `status` — `open`, `remediation_in_progress`, or `closed`
  - `issuedDate` — When the finding was issued
  - `examinationId` — Parent examination
  - `examinationName` — Parent examination name
</ResponseField>

## Create remediation item

<ParamField path="method" type="POST">`/api/examinations/{examId}/remediation-items`</ParamField>

Creates a new remediation item for an archived examination.

<ParamField path="examId" type="string" required>
  Examination ID. Must be in `archived` status.
</ParamField>

<ParamField body="title" type="string" required>
  Finding title.
</ParamField>

<ParamField body="description" type="string">
  Detailed finding description.
</ParamField>

<ParamField body="category" type="string" required>
  Regulatory category (e.g., `internal_controls`, `cdd_kyc`). Uses the regulation type's categories.
</ParamField>

<ParamField body="issuedDate" type="string">
  ISO date when the finding was issued.
</ParamField>

<ParamField body="linkedRequestItemIds" type="array" required>
  Array of request item IDs from the examination that led to this finding. At least one required.
</ParamField>

<ResponseField name="data.remediationItem" type="object">
  The created remediation item with auto-generated ID (e.g., `REM-2026-001`).
</ResponseField>

## Update remediation item

<ParamField path="method" type="PATCH">`/api/remediation-items/{itemId}`</ParamField>

<ParamField path="itemId" type="string" required>
  Remediation item ID (e.g., `REM-2026-001`).
</ParamField>

<ParamField body="title" type="string">
  Updated title.
</ParamField>

<ParamField body="description" type="string">
  Updated description.
</ParamField>

<ParamField body="issuedDate" type="string">
  Updated issued date.
</ParamField>

<ParamField body="status" type="string">
  New status. Transitions are forward-only: `open` → `remediation_in_progress` → `closed`.
</ParamField>

<Warning>
Status transitions are forward-only. You cannot move a remediation item back to a previous status.
</Warning>

<ResponseField name="data.evidence" type="array">

</ResponseField>

## Upload remediation evidence

<ParamField path="method" type="POST">`/api/remediation-items/{itemId}/evidence`</ParamField>

Upload a file demonstrating remediation progress.

<ParamField body="file" type="file" required>
  The evidence file. Max 50 MB. Allowed: PDF, DOCX, XLSX, CSV, PNG, JPG.
</ParamField>

<ResponseField name="data.evidence" type="object">
  The created evidence record.
</ResponseField>
